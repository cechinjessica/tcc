# tcc
Projeto de TCC IFRS 2019/2


Estou cursando a disciplina Trabalho de Conclusão Curso no 6º semestre do Curso Técnico em Informática-IFRS Câmpus Erechim.
Em uma displina anterior, eu fiz um projeto inicial e agora estou usando-o como base para o TCC.

A ideia é um gerenciador de contratos, a princípio para compra e venda de veículos. 
O contrato será gerado apartir de formulários e, ao fim do processo, disponibilizado em pdf.
A plataforma será a web, para gerenciar o banco de dados usarei MySQL.

A princípio, não é um projeto de difícil implementação por isso tentarei focar mais no design com Bootstrap.
